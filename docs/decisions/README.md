## FORMATO DE UM ADR
Cada documento segue o padrão:
- **Status:** aceito | substituído | revertido
- **Contexto:** o problema ou dilema que motivou a decisão.
- **Decisão:** o que foi formalmente adotado.
- **Motivo:** justificativa técnica ou de gameplay.
- **Consequências:** benefícios obtidos e concessões aceitas.
