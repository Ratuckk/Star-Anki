Rádio: texto aparecendo letra por letra

Cada opção mantém a mesma fala e velocidade base. A diferença é a presença visual: discreta, com pulso de comunicação, ou com speedlines para falas de habilidade.

Opção 1 — Terminal limpo

Digitação constante com cursor. A mais legível e silenciosa visualmente.

FFALCO // CANAL ABERTO

Opção 2 — Varredura de rádio

Cada letra ganha uma microentrada e o painel recebe um pulso de transmissão.

PPEPPY // CANAL ABERTO

Opção 3 — Speedlines de habilidade

Speedlines entram rápido, desaceleram durante a frase e retomam no final. Mais destaque para ability quotes.

MMIYU // HABILIDADE
